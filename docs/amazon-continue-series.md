# Amazon 新刊チェック

## 情報源

情報源はAmazonの「読み始めたシリーズの続きを読むにはこちら」ページである。現時点では、次のURLを基礎にする。

```text
https://www.amazon.co.jp/amz-books/seeMore/?widgetId=desktop-books-storefront_ContinueSeriesDRS_V2&title=読み始めたシリーズの続きを読むにはこちら&sourceType=RECS&page=1&filters=v1:FORMAT[kindle_edition]&metadata=...&cardFeedType=widgetId&ccs_id=<generated-uuid>
```

URLに含まれる `pd_rd_*`、`pf_rd_*`、`ref_` は表示時の推薦リクエストやセッションに依存するため固定しない。`metadata` は端末種別を表す固定値としてURLに含める。`ccs_id` はこのページで推薦カードを返すために必要であり、開くたびに生成し、CookieやDBへ保存しない。`page` はページング用、`filters` はKindle版への絞り込み用である。

## 取得方法

「新刊チェック」タブは表示の切り替えだけを行う。タブ内の「再チェック」を押すと、ローカルアプリデータ配下の `amazon-webview` をデータ領域とする専用WebViewを非表示で開く。ログアウト状態なら、目的ページにあるAmazon公式ログインリンクへ非表示のまま遷移し、ログイン画面の読み込み後だけ前面へ表示する。ログイン完了後はリンクの `openid.return_to` により目的ページへ戻り、候補を取得して専用WebViewを閉じる。ログイン済みなら、画面を表示せずに取得して閉じる。初期化スクリプトがAmazonページ内の `CBBE_BooksCardsReactAssets_cardsToRender` の `asinList` を読み取り、ASIN・タイトル・価格・評価表示の有無・書影URLをRust側へ渡す。書影URLはAmazonの画像配信ホストに属するHTTPS URLだけを保存し、カードに含まれない場合はASINからAmazon公式の書影URLを組み立てる。

画面は未確認・取得中・ログイン待ち・取得成功・取得失敗を区別する。ログイン待ちのときは「ログイン画面を表示」で専用画面を再表示できる。成功時は最終取得成功日時、Amazonからの取得件数、価格等の条件を満たして保存した件数、所蔵状況・設定との照合後のシリーズ数を表示する。成功日時と取得・保存件数は候補と同じトランザクションで保存するため、0件の成功も再起動後に確認できる。再起動後に表示される前回の成功は、現在のログイン状態の保証ではない。旧バージョンの保存済み候補に成功記録がない場合は未確認として扱う。

ページ内の候補を約60秒間読み取れない場合は取得失敗を通知する。ページ自体が読み込めない場合や連携スクリプトが動かない場合も、最後のページ読み込みから約90秒で失敗とする。ログイン入力待ちはこの時間制限の対象外で、画面を閉じると未完了として通知する。失敗時は前回成功時の候補・日時を保持し、前回の結果であることを明示する。CAPTCHAなどのアクセス確認は取得失敗として区別し、成功した0件の結果として保存しない。

Cookie、`ajaxContext`、`ccs_id`、ページHTML全体はアプリのDBへ渡さない。AmazonへのログインやCookieの管理はWebViewに任せる。取得結果は中央ペインの「新刊チェック」タブだけに表示し、通常のライブラリ一覧には混在させない。候補のシリーズ名を押すと、フィルターを解除して「ライブラリ」タブへ移り、手元の同シリーズの巻一覧を表示する。

## 表示判定

Amazonカードのタイトルに対して、既存のシリーズ推定処理を使う。次の条件をすべて満たす候補だけを中央ペインへ表示する。

1. ASINが手元のアクティブなKindleライブラリに存在しない。
2. 推定したシリーズ名が、手元の書籍の有効シリーズ名と一致する。
3. 推定巻数が、手元の同シリーズの最大巻数より大きい。
4. シリーズ名と巻数を安全に推定できる。
5. Amazonカードから価格を取得できる。

設定の「発売前の新刊を除外」が有効な場合は、評価が表示されていない候補を予約商品とみなして表示しない。この判定はAmazonカードの評価項目またはカードDOMの星評価表示に基づくため、販売日そのものを取得するものではない。`seeMore` カードの `averageRatingValue`、`reviewInfo.reviewCount`、`reviewInfo.reviewStarInfo` と、ストアカードの `starCountAlt`、`starCountShortDisplayString`、`fullStarCount`、`numberReviews` を評価の根拠として扱う。数値の0、空の表示、レビューURLだけでは評価ありとしない。これらの項目を読み取らずに保存した旧データは「再チェック」で更新する。発売済みでも評価のない作品はこの設定で除外され得る。

この判定は「未購入」をAmazonの購入情報で検証するものではない。Amazonページにはその情報が見当たらないため、Amazonの推薦と手元の所蔵状況を組み合わせた「続刊候補」である。無料配布やKindle Unlimitedで取得した序盤巻がライブラリに存在する場合も、手元の最大巻数に含めることで、後続部分を優先して表示する。価格不明の商品は予約受付前とみなし、価格が取得できるようになるまで表示しない。

## 制限

- AmazonページのHTML構造や埋め込みデータ名が変更されると取得できない。
- タイトルからシリーズ名・巻数を推定できない作品は表示しない。
- Amazonの推薦に出ない作品や、ページ1に含まれない作品は対象外である。
- 手元のKindleキャッシュにない購入済み巻を完全には判別できない。
- 「Amazon連携を解除」は専用WebViewの閲覧データと保存済み候補を削除する。ChromeのCookieやAmazon本体のアカウント状態には触れない。
