# シリーズ推定

## 目的

主要 XML に series 情報がないため、タイトルから候補を得る。ただし推定値を Amazon 由来の確定情報として扱わず、ユーザーが手動で上書きまたは無効化できるようにする。

## 推定段階

一冊のタイトルから、series name、volume index、confidence を抽出する。

単独で `high` とする形式（末尾の非数値の括弧書き、角括弧書きは先に除外する）:

- `第3巻`
- `3巻`
- `Vol. 3`, `Vol 3`, `Volume 3`
- `(3)`, `（3）`
- `#3`

単なる末尾数字は `contextual` とする。巻数の後ろに副題が続く場合は、数値部分だけを除いたタイトルを照合テンプレートとして扱う。いずれも同じ候補に異なる巻数が二つ以上存在するときだけ、蔵書全体の照合で採用する。これにより、発行年、版番号、商品番号などを一冊だけでシリーズと誤認することを避ける。

例:

- `星巡り 6巻 (青空コミックス)` → `星巡り` / 6 / `high`
- `星巡り: 5【イラスト特典付】 (青空コミックス)` → 同じ語幹の別巻がある場合だけ採用
- `星巡り 2 ～北の章～ (青空コミックス)` → `星巡り 北の章` / 2 / `contextual`

この規則は一般的な裸数字を完全には識別できない。誤推定は右ペインから `none` または `manual` へ切り替えて訂正でき、手動設定が自動推定より常に優先される。

全角数字と全角 ASCII は比較前に半角へ寄せ、前後空白と連続空白を正規化する。照合キーでは大文字小文字、空白、代表的な区切り記号の差を無視するが、表示名には元タイトルから切り出した文字列を使う。

## グループ表示

有効な series name を持つ二冊以上をシリーズカードにまとめる。一冊だけの場合は通常の単巻カードとして表示する。シリーズカードは代表表紙、シリーズ名、冊数を表示し、開くと巻数順の一覧へ移動する。

代表表紙は最小の有効 volume index を持つ本から選ぶ。同じ巻数または巻数不明がある場合は title、ASIN の順で安定して決める。

## 手動設定

右ペインから `auto`、`manual`、`none` を切り替えられる。`manual` では series name と volume index を編集できる。この値は Kindle 再同期で変更しない。

自動推定規則を将来変更しても手動設定は再計算しない。自動推定値は同期時に再計算してよい。
